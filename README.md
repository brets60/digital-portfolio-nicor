## Overview

A premium, editorial digital portfolio combining clean typography, responsive design, and interactive hardware simulators. Designed for authenticity, clarity, and real-world engineering rigor.

### Key Highlights
- **Direct First-Sight Identity**: Portrait presentation right in the opening hero section with live availability status.
- **Flagship Project**: **Speed Detection and Warning System** (ESP32-CAM, Arduino Uno, Python, OpenCV, SQLite) with an interactive in-browser radar simulator and SQLite event ledger.
- **Refined Typography**: Space Grotesk (display & headlines) + Plus Jakarta Sans (body prose).
- **Editorial Motion Design**: Top reading progress indicator, infinite ticker marquee ribbon, interactive capability accordion, and tactile micro-interactions powered by Framer Motion.
- **Audio Feedback**: Tactile Web Audio API sound synthesis with mute toggle.

## Local Development

```bash
# Clone the repository
git clone https://github.com/brets60/digital-portfolio-nicor.git

# Navigate to project directory
cd digital-portfolio-nicor

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
